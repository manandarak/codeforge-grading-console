# Bug Fix Log

I reproduced every bug in the original file (`original.html`) in Google Chrome using a Playwright script and the test files in `samples/`. Each fix was then checked by the automated suite in `tests/test.py` (47 checks, all passing) and by hand in the browser.

**Assumptions I made:**
- The brief's example "80.2 → 81" looked like a typo, so I used standard rounding to the nearest integer.
- For a duplicate BITS ID within the same course, the app keeps the first row and flags the rest rather than guessing which one is correct.
