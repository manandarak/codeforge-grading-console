Marks file format guidance
  • The first sheet must have three columns: BITS ID, Course and Total Marks. Header spelling and case are flexible, and extra columns are ignored.
  • Total Marks should be whole numbers from 0 to 100. Fractional values are rounded to the nearest integer (80.4 → 80, 80.5 → 81) and flagged so you can check them.
  • Students who did not appear for the examination and are to receive an NC grade should not be in the file. Rows with blank marks are excluded and listed for you.
  • A file can contain several courses. You grade one course at a time.
